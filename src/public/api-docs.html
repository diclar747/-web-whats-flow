WhatsApp API Documentation

API completa de WhatsApp usando Baileys con respuestas en formato JSON

GET /api/status

Obtiene el estado actual de la conexión y toda la información disponible

Ejemplo de uso:

GET http://localhost:3001/api/status

Respuesta exitosa:

{ "phoneNumber": "5511999999999", "pushName": "Usuario", "platform": "android", "connected": true, "lastSeen": "2024-01-01T12:00:00.000Z", "groups": [ { "id": "123456789@g.us", "subject": "Nombre del Grupo", "participants": 50, "creation": 1234567890 } ], "contacts": [], "qr": null, "status": "connected", "timestamp": "2024-01-01T12:00:00.000Z" }

GET /api/qr

Obtiene el código QR para la autenticación de WhatsApp Web

Ejemplo de uso:

GET http://localhost:3001/api/qr

Respuesta exitosa:

{ "status": "success", "qr": "data:image/png;base64,...", "timestamp": "2024-01-01T12:00:00.000Z" }

POST /api/send-message

Envía un mensaje de WhatsApp a un número específico

Cuerpo de la petición:

{ "number": "5511999999999", "message": "¡Hola! Este es un mensaje de prueba" }

Respuesta exitosa:

{ "status": "success", "message": "Mensaje enviado exitosamente", "timestamp": "2024-01-01T12:00:00.000Z", "details": { "to": "5511999999999", "messageContent": "¡Hola! Este es un mensaje de prueba" } }

Ejemplo con curl:

curl -X POST http://localhost:3001/api/send-message \ -H "Content-Type: application/json" \ -d '{"number":"5511999999999","message":"¡Hola mundo!"}'

GET /api/groups

Obtiene la lista de todos los grupos en los que participa el número

Ejemplo de uso:

GET http://localhost:3001/api/groups

Respuesta exitosa:

{ "status": "success", "timestamp": "2024-01-01T12:00:00.000Z", "groups": [ { "id": "123456789@g.us", "subject": "Nombre del Grupo", "participants": 50, "creation": 1234567890 } ] }

GET /api/group/:groupId/members

Obtiene la lista de participantes de un grupo específico

Ejemplo de uso:

GET http://localhost:3001/api/group/123456789@g.us/members

Respuesta exitosa:

{ "status": "success", "timestamp": "2024-01-01T12:00:00.000Z", "groupId": "123456789@g.us", "participants": [ { "id": "5511999999999@s.whatsapp.net", "admin": "superadmin" } ] }

Eventos WebSocket

La API utiliza Socket.IO para comunicación en tiempo real

'connection-info'

Emitido cuando hay cambios en el estado de la conexión

socket.on('connection-info', (info) => { console.log('Estado de conexión:', info); // info contiene toda la información del estado actual });

'message'

Emitido cuando se recibe un nuevo mensaje

socket.on('message', (message) => { console.log('Nuevo mensaje:', { from: message.from, content: message.content, timestamp: message.timestamp, type: message.type }); });

Ejemplo de Conexión con Socket.IO

const socket = io('http://localhost:3001'); // Escuchar eventos socket.on('connect', () => { console.log('Conectado al servidor'); }); socket.on('connection-info', (info) => { // Manejar actualizaciones de estado console.log('Estado actual:', info); }); socket.on('message', (message) => { // Manejar mensajes entrantes console.log('Mensaje recibido:', message); });
