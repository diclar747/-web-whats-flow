WhatsApp API Documentation

Información General

Base URL: http://localhost:3001

Autenticación

  • No se requiere autenticación para los endpoints
  • Es necesario escanear el código QR para conectar WhatsApp
  • La sesión se mantiene activa hasta que se cierre manualmente o se desconecte WhatsApp

Endpoints

1. Conexión y Estado

1.1 Obtener Código QR

GET /qr

Retorna una página web con el código QR para escanear.

1.2 Obtener Estado de Conexión

GET /status

{
    "connected": true,
    "timestamp": "2024-01-01T00:00:00.000Z"
}

2. Mensajes

2.1 Enviar Mensaje de Texto

POST /api/send/text

Body:

{
    "number": "5511999999999",
    "message": "Texto del mensaje"
}

2.2 Enviar Imagen

POST /api/send/image

Body:

{
    "number": "5511999999999",
    "imageUrl": "https://ejemplo.com/imagen.jpg",
    "caption": "Descripción opcional"
}

2.3 Enviar Video

POST /api/send/video

Body:

{
    "number": "5511999999999",
    "videoUrl": "https://ejemplo.com/video.mp4",
    "caption": "Descripción opcional"
}

2.4 Enviar Audio

POST /api/send/audio

Body:

{
    "number": "5511999999999",
    "audioUrl": "https://ejemplo.com/audio.mp3",
    "ptt": false
}

2.5 Enviar Documento

POST /api/send/document

Body:

{
    "number": "5511999999999",
    "documentUrl": "https://ejemplo.com/documento.pdf",
    "fileName": "documento.pdf",
    "mimetype": "application/pdf"
}

3. Grupos

3.1 Obtener Lista de Grupos

GET /api/groups

3.2 Obtener Información de un Grupo

GET /api/group/:groupId

Ejemplos de Uso

cURL

// Enviar mensaje
curl -X POST http://localhost:3001/api/send/text \
  -H "Content-Type: application/json" \
  -d '{"number":"5511999999999","message":"¡Hola mundo!"}'

// Enviar imagen
curl -X POST http://localhost:3001/api/send/image \
  -H "Content-Type: application/json" \
  -d '{
    "number":"5511999999999",
    "imageUrl":"https://ejemplo.com/imagen.jpg",
    "caption":"Mi imagen"
  }'

JavaScript

// Enviar mensaje
async function sendMessage(number, message) {
    try {
        const response = await fetch('http://localhost:3001/api/send/text', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify({ number, message })
        });
        const data = await response.json();
        return data;
    } catch (error) {
        console.error('Error:', error);
    }
}

Límites y Restricciones

Archivos Multimedia

Tipo Tamaño Máximo Formatos
Imágenes 5MB jpg, jpeg, png
Videos 16MB mp4, 3gp
Documentos 100MB pdf, doc, docx, xls, xlsx, ppt, pptx

Notas Importantes

  • Es necesario escanear el QR antes de usar la API
  • La conexión se mantiene hasta que se cierre manualmente
  • Si se pierde la conexión, se intentará reconectar automáticamente
  • Los mensajes se envían en orden de llegada
  • Las URLs de archivos multimedia deben ser accesibles públicamente
