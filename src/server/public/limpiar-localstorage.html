🧹 Limpiar Caché Local

⚠️ Esta acción borrará todos los datos locales del navegador

Presiona el botón para eliminar todas las sesiones almacenadas localmente:

¿Qué se eliminará?
• Sesiones locales (localStorage)
• Sesiones temporales (sessionStorage)
• Cookies del sitio
• Caché del navegador
• Estado de las aplicaciones
✨ ¡Caché local limpiado exitosamente!
Ahora puedes intentar escanear el código QR nuevamente.
💡 Consejo: Después de limpiar el caché, puedes cerrar y abrir nuevamente el navegador para mejor resultado.
