🚀 INSTRUCCIONES PARA USAR AHORA
════════════════════════════════════════════════════════════════════

PASO 1️⃣ - LIMPIAR CACHÉ (MUY IMPORTANTE)
────────────────────────────────────────

Presiona: Ctrl + Shift + Delete

Marca todas estas opciones:
  ☑ Cookies
  ☑ Cached images and files  
  ☑ Local Storage
  ☑ Session Storage

Período: "Todo el tiempo" o "desde siempre"

Click: "Borrar datos"

PASO 2️⃣ - RECARGAR PÁGINA
────────────────────────

Presiona: Ctrl + Shift + R

(O mantén F5 presionado 2-3 segundos)

PASO 3️⃣ - VERIFICAR QUE APARECE QR
──────────────────────────────────

Debe ver:
  ✓ Pantalla de "Conectar WhatsFlow"
  ✓ Código QR visible
  ✓ Texto "Escanea el código QR"

PASO 4️⃣ - ESCANEAR CON WHATSAPP
───────────────────────────────

1. Abre WhatsApp en tu teléfono
2. Usa la cámara para escanear el QR
3. Aparecerá pantalla de confirmación
4. Confirma la conexión

PASO 5️⃣ - VERIFICAR EN CONSOLA (OPCIONAL)
──────────────────────────────────────────

Para verificar que todo funciona correctamente:

1. Abre DevTools (F12)
2. Abre la pestaña "Console"
3. Busca estos mensajes:
   ✓ "🔌 connection-update recibido:"
   ✓ "✅ Sesión lista, conectando:"
   ✓ "📱 Chats cargados exitosamente"

PASO 6️⃣ - VERIFICAR DASHBOARD
──────────────────────────────

Cuando todo funciona correctamente:
  ✓ Pantalla cambia a Dashboard
  ✓ Lista de chats aparece
  ✓ Se pueden ver mensajes
  ✓ Sistema completamente operativo
