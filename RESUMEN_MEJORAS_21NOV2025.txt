⚠️ IMPORTANTE: REQUISITO PARA ENVÍO
───────────────────────────────────────────────────────────────────────────────

Para que los agentes puedan ENVIAR mensajes:

  ⚠️ EL ADMIN DEBE TENER WHATSAPP CONECTADO

  Pasos:
  1. Abrir https://web.whats-flow.com como admin
  2. Escanear código QR con WhatsApp
  3. Esperar mensaje "Conectado"
  4. Ahora los agentes pueden enviar mensajes

  Esto es porque el agente usa el sessionId del admin para enviar.
