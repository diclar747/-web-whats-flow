1. PLANTILLAS DE MENSAJES
   ━━━━━━━━━━━━━━━━━━━━━━━━━
   ✓ 3 plantillas predefinidas disponibles
   ✓ Selecciona una al crear la campaña
   ✓ O escribe tu mensaje personalizado
   ✓ Usa variables: {nombre}, {dato1}, {dato2}, {dato3}, {fecha}

2. CONFIGURACIÓN DE RECORDATORIOS
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   ✓ Mismo día del vencimiento
   ✓ 1 día antes
   ✓ 2 días antes
   ✓ 3 días antes
   ✓ 1 semana antes

3. HORARIOS INTELIGENTES
   ━━━━━━━━━━━━━━━━━━━━━━━
   ✓ Solo envía entre 07:00 - 18:00 (configurable)
   ✓ Evita horarios inapropiados
   ✓ Respeta zonas horarias

4. INTERVALOS ALEATORIOS
   ━━━━━━━━━━━━━━━━━━━━━━━━
   ✓ Cada mensaje en horario diferente
   ✓ Defecto: 60-120 segundos entre mensajes
   ✓ Evita detección de spam
   ✓ Envíos naturales y seguros

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 PASOS PARA USAR EL SISTEMA                                                │
└──────────────────────────────────────────────────────────────────────────────┘

PASO 1: CONFIGURAR (hacer una vez)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Clic en botón "Configuración" (en el header)
2. Seleccionar cuándo enviar recordatorio (ej: 1 día antes)
3. Definir horario de envío (ej: 07:00 - 18:00)
4. Configurar intervalo entre mensajes (ej: 60-120 segundos)
5. Guardar configuración

PASO 2: CREAR CAMPAÑA
━━━━━━━━━━━━━━━━━━━━━━
1. Clic en "Nueva Campaña"
2. Ingresar nombre de la campaña
3. Descargar plantilla Excel (botón en el header)
4. Llenar el Excel con fechas de VENCIMIENTO
5. Cargar el Excel
6. Seleccionar plantilla de mensaje o escribir personalizado
7. (Opcional) Adjuntar archivo multimedia
8. Crear campaña

PASO 3: ENVÍO AUTOMÁTICO
━━━━━━━━━━━━━━━━━━━━━━━━━
✓ El sistema revisa cada minuto
✓ Calcula automáticamente cuándo enviar
✓ Solo envía en horario permitido
✓ Usa intervalos aleatorios

│ 💡 EJEMPLO COMPLETO                                                          │

ESCENARIO: Recordatorios de pago de mensualidades
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. CONFIGURACIÓN:
   ├─ Recordatorio: 1 día antes
   ├─ Horario: 09:00 - 17:00
   └─ Intervalo: 60-120 segundos

2. EXCEL:
   ┌─────────────┬─────────────┬──────────┬──────────┬────────────┐
   │ 573001234   │ Juan Pérez  │ $150.000 │ Cuota #3 │ 2025-11-30 │
   └─────────────┴─────────────┴──────────┴──────────┴────────────┘

3. PLANTILLA SELECCIONADA:
   "Hola {nombre}, te recordamos que tu pago de {dato1} 
    vence el {fecha}. ¡Gracias por tu confianza! 😊"

4. RESULTADO:
   ├─ Fecha de vencimiento: 30/11/2025
   ├─ Fecha de envío: 29/11/2025 (1 día antes)
   ├─ Horario: Entre 09:00 y 17:00
   ├─ Intervalo: Aleatorio 60-120 seg entre cada mensaje
   └─ Mensaje: "Hola Juan Pérez, te recordamos que tu pago 
               de $150.000 vence el 2025-11-30. ¡Gracias!"
