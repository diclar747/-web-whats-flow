OPCIÓN 1 (Recomendada): Usar servidor de producción real
  - Este es un ambiente de desarrollo
  - Tu servidor de producción ya debe tener todo configurado
  - Ejecuta allí: bash /ruta/completa/deploy.sh

OPCIÓN 2: Completar package.json
  - Agregar todas las dependencias faltantes al package.json
  - Ejecutar: npm install
  - Reiniciar: pm2 restart whatsflow-server

OPCIÓN 3: Deployment manual inmediato
  Si tu servidor de producción está en otra máquina:

  1. Conecta vía SSH:
     ssh usuario@tu-servidor.com

  2. Ve al directorio:
     cd /home/user/-web-whats-flow

  3. Ejecuta deployment:
     bash deploy.sh

  4. Verifica que PM2 esté corriendo:
     pm2 list

  5. Si PM2 no está, instálalo:
     npm install -g pm2
     pm2 start ecosystem.config.js
     pm2 save
